# برنامج ضفاف العربية

موقع مسابقات مباشرة (مثل كاهوت) لفصول المدرسة من الصف التاسع إلى الثاني عشر، يدعم دوري خروج المغلوب ومسابقات منفصلة تُجرى لكل فصل وتُقارن نتائجها.

## الصفحات

| الصفحة | الرابط | الوصف |
|---|---|---|
| الافتتاحية والرئيسية | `/` | زر لبدء الافتتاحية، ثم أهداف البرنامج قبل دخول الموقع |
| عن البرنامج | `/about` | نبذة البرنامج وأهدافه ومجالات المسابقات والفئة المستهدفة |
| الطالب | `/play` | يختار الصف والفصل ويكتب اسمه ويجاوب من جهازه |
| شاشة العرض | `/display` | للبروجكتر: الأسئلة، التوقيت، الإجابات، المراكز، شجرة الدوري |
| الأدمن | `/admin` | الفصول والأسئلة، الدوري، زر بدء المسابقة، الإحصائيات |

كلمة مرور الأدمن: من ملف `app/admin_password.txt` أو المتغير `ADMIN_PASSWORD` (وإلا `admin123`)، ويمكن تغييرها من صفحة الإعدادات في لوحة الأدمن.

## التشغيل المحلي

1. ثبّت [Python](https://www.python.org/downloads/) (3.10 أو أحدث) — في ويندوز فعّل خيار "Add Python to PATH".
2. ويندوز: اضغط مرتين على `start.bat` — أو من الطرفية:
   ```
   pip install -r requirements.txt
   python -m uvicorn app.main:app --host 0.0.0.0 --port 8000
   ```
3. افتح `http://localhost:8000/admin`، والطلاب يدخلون من الرابط أو رمز QR الظاهر في شاشة العرض (نفس شبكة الواي فاي).

## طريقة الاستخدام

عند فتح رابط الموقع الرئيسي تظهر شاشة فيها زر «افتح الموقع». بعد الضغط تظهر أهداف البرنامج مع احتفالية بسيطة؛ اضغط Enter أو زر المتابعة لإخفاء الافتتاحية وإظهار الموقع وروابط الطالب وشاشة العرض ولوحة الأدمن.

1. **الفصول والأسئلة**: أنشئ الفصول (مثلاً 10/1، 10/2) ثم اضغط "الأسئلة" لكل فصل، اختر عدد الأسئلة، واكتب السؤال والإجابة الصحيحة والخيارات الخاطئة ووقت كل سؤال. لكل فصل أسئلته الخاصة، ويمكن نسخ الأسئلة بين الفصول.
2. **الدوري والجولات**: اختر نوع المسابقة:
   - **دوري خروج المغلوب**: اختر الفصول المشاركة وعدد الأسئلة في كل مباراة وطريقة المواجهات (حسب الصف أو قرعة)، فيُنشأ جدول خروج المغلوب تلقائياً.
   - **مسابقات منفصلة للفصول**: اختر فصلاً واحداً أو أكثر. يجيب كل فصل عن جميع أسئلته الخاصة، وكل طالب ينتقل للسؤال التالي فور إجابته دون انتظار الأدمن أو بقية الطلاب. تُحفظ نتيجة كل فصل ويُعرض ترتيب المقارنة بمتوسط نقاط من 5 لكل سؤال، مع الدقة ومتوسط زمن الإنهاء. الإجابة الخاطئة لا تمنح نقاطاً، والإجابة الصحيحة تمنح حتى 5 نقاط بحسب سرعة الإجابة.
3. **التحكم المباشر**: في دوري خروج المغلوب اضغط "فتح المباراة"، ينضم طلاب الفصلين، ثم "ابدأ المسابقة". كل فصل يرى أسئلته في نفس اللحظة، والنقاط حسب صحة الإجابة وسرعتها (+ مكافأة للإجابات المتتالية). في المسابقات المنفصلة افتح أكثر من فصل من بطاقاته؛ لكل فصل أسئلته وتوقيته ومساره الخاص وتعمل المسابقات بالتوازي. ينضم الطلاب تلقائياً إلى مسابقة فصلهم، ويتقدم كل طالب ذاتياً، ويُرتب الأداء بالنقاط ثم الدقة ثم سرعة إنهاء الاختبار.
4. **شاشة العرض والافتتاحية**: اضغط "ابدأ الافتتاحية" على شاشة العرض لعرض عدّ تنازلي واحتفال قصير ثم الانتقال تلقائياً إلى المسابقات المباشرة. استخدم زر ملء الشاشة لعرضها على البروجكتر.

**حساب النتيجة**: في دوري المواجهات يُحسب متوسط نقاط الفصل، ثم الدقة، ثم سرعة الإجابة؛ وفي المسابقات المنفصلة يُرتب الفصل بمتوسط النقاط من 5 لكل سؤال، ثم الدقة، ثم متوسط زمن إكمال الاختبار.


البيانات تُحفظ في `data/db.json` (أو `/data/db.json` على الخادم).
